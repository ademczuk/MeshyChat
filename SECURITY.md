# Security

## Reporting a vulnerability

Please report a vulnerability privately through GitHub's "Report a vulnerability" button (private vulnerability
reporting, under the Security tab of this repository). Do not open a public issue or pull request for it.

Include what you did, what you expected, what happened, and the commit you tested. If you have a proof of concept,
attach it to the private report.

## What to read first

[THREAT-MODEL.md](THREAT-MODEL.md) says what the system protects, which opt-in features let a message carry
operator authority, and how reports are rated.

## Supported versions

This is an early release. Fixes go to the main branch only.
